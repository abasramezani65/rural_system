# سامانه پایش خدمات روستایی — نسخه پایتون (Flask + SQLite)

این نسخه از سامانه با موتور پایتون بازنویسی شده و دارای ویژگی‌های زیر است:

## ویژگی‌های جدید
- **Backend پایتون (Flask)**: سرور سبک و قابل اعتماد
- **پایگاه داده SQLite**: ذخیره متمرکز داده‌ها، دسترسی همزمان همه کاربران به یک منبع داده
- **احراز هویت سرور-side**: نشست‌های امن با کوکی HttpOnly
- **فونت Vazirmatn**: ظاهر شکیل و مدرن فارسی
- **صفحه ورود شکیل**: طراحی کارت با گرادیان و انیمیشن
- **منوهای کشویی**: ۶ کارت قابل جمع‌شدن در پنل مدیریت
- **نمودار آماری**: نمودار میله‌ای توزیع خدمات + نمودار دایره‌ای بر اساس استان (Chart.js)
- **تم تاریک/روشن**: با ذخیره در مرورگر
- **طراحی واکنش‌گرا (ریسپانسیو)**: موبایل و دسکتاپ
- **سطح دسترسی**: کاربر کشوری، استانی، شهرستانی

## اجرای سریع

```bash
cd rural_system
python3 app.py
```

سپس مرورگر را روی http://localhost:5050 باز کنید.

**ورود پیش‌فرض:**
- نام کاربری: `admin`
- رمز عبور: `admin12345`

## پیش‌نیازها

```bash
pip install flask
```

(Python 3.8+ لازم است. SQLite در پایتون داخلی است و نیازی به نصب جداگانه ندارد.)

## ساختار پروژه

```
rural_system/
├── app.py             # فایل اصلی Flask (مسیرها و API)
├── db.py              # توابع پایگاه داده
├── schema.sql         # ساختار جداول SQLite
├── rural.db           # پایگاه داده (خودکار ساخته می‌شود)
├── templates/
│   └── index.html     # صفحه اصلی
└── static/
    ├── css/styles.css # استایل‌ها (شامل تم تاریک)
    └── js/app.js      # منطق فرانت‌اند
```

## API Endpoints

### احراز هویت
- `POST /api/login` — ورود
- `POST /api/logout` — خروج
- `GET /api/me` — اطلاعات کاربر فعلی
- `GET /api/state` — بارگذاری اولیه همه داده‌ها

### مدیریت رکوردها
- `GET /api/records` — لیست رکوردها
- `POST /api/records` — ثبت یا ویرایش رکورد
- `DELETE /api/records/<id>` — حذف رکورد

### مدیریت پایه
- `GET/POST /api/roles` — سمت‌ها
- `GET/POST /api/services` — خدمات
- `GET/POST /api/provinces` — استان‌ها
- `POST/DELETE /api/counties` — شهرستان‌ها

### پشتیبان‌گیری
- `GET /api/export/csv` — خروجی CSV
- `GET /api/export/json` — خروجی JSON کامل

## استقرار روی سرور (VPS)

```bash
# 1. کپی فایل‌ها روی سرور
scp -r rural_system/ user@your-server:/opt/

# 2. نصب وابستگی‌ها
pip install flask gunicorn

# 3. اجرا با Gunicorn (تولید)
cd /opt/rural_system
gunicorn -w 4 -b 0.0.0.0:5050 app:app

# 4. (اختیاری) استفاده از Nginx به عنوان reverse proxy
```

## مزایا نسبت به نسخه HTML قبلی

| ویژگی | نسخه قبلی (HTML) | نسخه پایتون |
|---|---|---|
| ذخیره داده | localStorage (هر مرورگر جدا) | SQLite متمرکز |
| دسترسی همزمان | خیر | بله |
| احراز هویت | سمت کلاینت (ناامن) | سمت سرور (امن) |
| تحلیل داده با pandas | خیر | بله |
| کاربران همزمان | ۱ (همان مرورگر) | ۱۰+ |
| پشتیبان‌گیری | دستی (JSON) | خودکار + CSV |

## پشتیبان‌گیری خودکار

برای پشتیبان‌گیری روزانه، این cron job را اضافه کنید:

```bash
# در crontab:
0 3 * * * cp /opt/rural_system/rural.db /opt/backups/rural_$(date +\%Y\%m\%d).db
```
